# ポートフォリオ公開サイト  

HTML, CSS, JavaScriptを用いて制作するポートフォリオサイトです。  
Webサイトの制作に加え、Git・GitHubによるバージョン管理や、GitHub Flowを用いた開発手法の取得を目的としています。　　

## 公開サイト  

**URL:**[https://Ketsuben.github.io/](https://Ketsuben.github.io/)  

GitHub Pagesを利用して公開しています。

## 仕様技術・開発環境  
- フロントエンド ...HTML5、CSS3、JavaScript　　
- 開発環境 ... Eclipse IDE  
- バージョン管理 ... Git/GitHub  
- 開発フロー ... GitHub Flow  
- ホスティング ... GitHub Pages  

## 開発・バージョン管理  
開発にはGitHub Flowを採用しています。  
  
  
バージョン番号は[Semantic Versioning](https://semver.org/lang/ja/)を参考に管理し、  
リリース持にはGitタグとGitHub Releaseを利用します。  
  
## 変更履歴・リリース情報  
各バージョンの変更履歴は、 Keep a Changelogを参考に'Changelog.md'で管理しています。  
  
  
- **[CHANGELOG.md](CHANGELOG.md)** -バージョンごとの変更内容
- **[GitHub Releases](https://github.com/Ketsuben/Ketsuben.github.io/releases)** - リリースノート・Gitタグ・ソースコード
